# 縮小AlphaZero v2

既存の `C:\Users\User\Desktop\chess` と
`/home/user/chess/alphazero_chess` を変更せず、別実験として動かす構成です。

## 通常の使い方

1. v1の強化学習とモデル比較を停止する。
2. `v2強化学習を起動.bat` を開く。
3. 初期設定のまま「v2連続学習をスタート」を押す。
4. 「ストップ」で安全に停止する。

初期値の1サイクルは、自己対局8局、2並列、1手50探索、学習64 stepです。
25サイクルごとに世代モデルを保存し、人間対戦・世代比較GUIの一覧へ追加します。

## GUI

- `v2強化学習を起動.bat`: v2だけを学習する。
- `v2チェスAIと対戦.bat`: 保存したv2モデルと人間が対局する。
- `v2モデル比較を起動.bat`: 保存した異なるv2世代同士を対戦させる。

v1とv2は同時にGPUを使わないでください。学習GUIと世代比較GUIは競合を検出して警告します。
