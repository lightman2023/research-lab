# 縮小AlphaZero v2

既存の `C:\Users\User\Desktop\chess` と
`/home/user/chess/alphazero_chess` を変更せず、別実験として動かす構成です。

## 通常の使い方

1. v1の強化学習とモデル比較を停止する。
2. `v2強化学習を起動.bat` を開く。
3. 初期設定のまま「v2連続学習をスタート」を押す。
4. 「ストップ」で安全に停止する。

初期値の1サイクルは、自己対局8局、2並列、1手50探索、学習64 stepです。
25サイクルごとに世代モデルを保存し、人間対戦・世代比較GUIの一覧へ追加します。

## GUI

- `v2強化学習を起動.bat`: v2だけを学習する。
- `v2チェスAIと対戦.bat`: 保存したv2モデルと人間が対局する。
- `v2モデル比較を起動.bat`: 保存した異なるv2世代同士を対戦させる。

v1とv2は同時にGPUを使わないでください。学習GUIと世代比較GUIは競合を検出して警告します。

## ループ対策の試験

`v2ループ対策試験を起動.bat` を開くと、自己対局の試験用GUIが起動します。
方式・モデル・対局数・探索回数・最大手数を選び、「試験対局を実行」を押してください。
進行と勝敗・終局理由の集計はGUI内の対局ログに表示され、対局データは
`arena_results` 内の試験専用フォルダに保存されます。
この試験結果は通常の学習データには加えません。
`v2モデル比較を起動.bat` は保存モデル同士の比較に使います。




## 2026-10-02 低学習率・自己対局モデル

`v2モデル比較を起動.bat` の「低学習率・自己対局」で新実験の保存モデルを選べます。cycle-000000は開始モデル、cycle-000010は10サイクル後です。探索・自己対局・arenaは実際の3回反復と50手ルールで自動引き分けに統一しています。自己対局・学習とモデル比較は同時に実行できません。新実験の継続学習は学習率0.0001の一定設定が必要です。従来の学習GUIはその設定に対応していないため、この実験の継続には使わないでください。


## 温度1の追加学習

`v2温度1学習を起動.bat` から学習率0.0001・温度1の実験GUIを開けます。初期値は10サイクル、保存間隔1です。詳しくは `温度1学習README.md`。比較には既存の `v2モデル比較を起動.bat` の「低学習率・温度1」を使います。
