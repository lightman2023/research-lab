# 50サイクル版からの学習率比較・128更新試験

## 結論

学習率0.001と0.0001を各128更新した。固定化は、評価した129局面で両条件とも0個だった。短い試験では過去に見られた固定化を再現できず、固定化を防ぐ条件は選べない。0.0001は0.001より検証誤差が小さかったが、開始モデルからの価値予測の改善は確認できなかった。

| 条件 | 固定化 / 129局面 | 価値MSE | 方策クロスエントロピー |
|---|---:|---:|---:|
| 開始モデル | 0 | 0.478639 | 3.133500 |
| A: 学習率0.001 | 0 | 0.486371 | 3.148832 |
| B: 学習率0.0001 | 0 | 0.479797 | 3.116358 |

誤差は小さい方がよい。数値差を統計的に検証したものではない。試行は乱数seed一つであり、棋力の改善や学習率の優劣を断定しない。

## 実行条件

- 実行日: 2026-09-28、日本時間。
- 対象: WSL `/home/user/chess/alphazero_chess_v2`。
- 開始モデル: 訪問回数版 `cycle-000050.msgpack`。SHA-256は `ab65125846a4a61c43c904afde3180d551fecd77f001b1e6fd224abd3575a4cc`。
- 元モデルを別実験へコピーし、原本のSHA-256が変わっていないことを実行後に確認した。
- 学習データ: 50サイクル保存時点までに生成された既存自己対局411局をコピー。教師値0の局面21204個、+1が539個、-1が530個。データ選択はファイル時刻に基づくため、過去の実際のミニバッチの復元ではない。
- 最適化: AdamW、weight decay=0.0001、batch size=64。各128更新。開始時の最適化状態は両条件とも新規作成。50サイクル時点の最適化状態を再現していない。
- 学習率以外の設定とデータ抽出順をそろえた。乱数seed=20260928。入力盤面・方策教師値・勝敗教師値を含む全バッチのSHA-256が両条件で完全一致した。
- 学習率は短い試験内で一定。既存の学習率スケジュールの最初の変更は50000更新のため、この128更新では変更されない。
- 新しい自己対局やモデル間の対局は実施していない。

## 評価方法

同じ129局面を0、32、64、96、128更新時点で評価した。初期・序盤3局面、反復引き分け対局から64局面、勝ち側31局面、負け側31局面。評価に使う自己対局ファイルと、今回の学習ファイルは重複しない。ただし、異なる対局に同じ盤面が現れることまでは除外していない。

固定化は価値用Dense_0の256成分すべてが0以下となり、ReLUで全成分ゼロになることと定義した。価値が0に近いだけの局面は固定化と数えない。

価値MSEは初期・序盤3局面を除く126局面の `(z-v)^2` の平均。`z`は自己対局の終局結果（勝ち+1、引き分け0、負け-1）、`v`は手番側から見たモデルの予測値。方策クロスエントロピーは、保存された探索の訪問割合を目標にした手の予測の誤差。評価セットは診断のため勝敗を多めに含めており、通常の自己対局の分布を代表しない。開始時点で価値MSEが約0.48なのは、この評価セットで勝敗の区別が弱いことを示す。

教師値と損失の位置づけは David Silverほか (2017), [*Mastering Chess and Shogi by Self-Play with a General Reinforcement Learning Algorithm*](https://arxiv.org/html/1712.01815v1), 式(1)に基づく。本文は今回の計画時と直前の調査で確認済み。学習率0.0001の選択はこの実装を調べるための独自の比較条件であり、論文の推奨値として扱わない。

## 残っている課題

- 過去の50→75サイクルには約1600更新があり、今回の128更新はその一部に相当するだけ。さらに過去は自己対局でデータが更新され、今回は固定データなので同じ経過ではない。
- より長い比較、別seedでの再確認、自己対局でデータを更新する条件が必要かは、今回の結果を踏まえて決める。
- この結果だけで0.0001を本番学習へ採用しない。反復の改善や棋力は未検証。
