# v2 訪問回数版（独立実験）

`v2訪問回数学習を起動.bat` で専用GUIを開きます。ログはGUI内に表示されます。

1. 「確認対局2局を実行」で新方式の自己対局データを作り、保存形式を検証します。
2. ログ末尾に `VERIFIED` が出たら、「学習1サイクルを実行」または「連続学習を開始」で自己対局と学習を進められます。「連続回数」を0にすると停止ボタンを押すまで続きます。有限回数も指定できます。
3. `latest.msgpack` は毎サイクル更新します。「世代保存間隔」は初期値25で、該当サイクルのモデルを `checkpoints/saved/` に別名で保存します。停止ボタンで途中停止できます。
4. 旧v2の学習GUIとは同時に実行しないでください。

開始モデルは `checkpoints/saved/cycle-000119.msgpack` のコピーです。新しい自己対局データ・学習状態・モデルは `experiments/raw-visits-v1/` の中に保存します。旧959局のデータは読み込みません。

手を選ぶ際は従来の温度設定を使い、学習用の方策目標には加工前のMCTS訪問割合を使います。反復禁止や駒得による仮の勝敗はこの実験には含めません。

「確認対局2局」はデータ形式の確認です。勝率や強さの評価ではありません。

## 引き分け請求の扱い（2026-09-27以降）

反復または50手ルールで引き分けを請求できる局面は、自動終了にせず、探索で「請求」と合法手を比較します。請求を選んだ場合だけ引き分けで終了します。五度反復や75手ルールなどの強制終了は従来どおりです。比較GUIから起動する `arena.py` にも同じ処理を適用し、棋譜に `DrawClaimRule` を記録します。

旧119サイクルと訪問回数版400サイクルのモデルは、請求可能時に自動終了するルールの自己対局から学んだものです。今後このGUIで学習を再開すると、既存の自己対局データと新ルールのデータが混ざります。新ルールだけで学習効果を比較する場合は、別のデータ保存先を用意してください。
